# Experiment performance never routes the recommendation

Phase 3 evaluates the work a User produces, which raises the question of
whether that evaluation should influence the Direction we give. It does not.
Two Users with identical preferences receive the same Direction regardless of
how well they performed. A User who performs poorly and reports enjoying the
work is still directed toward that work.

We refuse performance-based routing because a single work sample cannot
measure aptitude, and a system that says "this is about what you enjoy" while
quietly steering on how well you did would be a hidden capacity evaluation —
the one dishonesty this product cannot afford.

Performance is not discarded, though. It has two legitimate jobs. First it is
the *stimulus*: a User cannot know whether they enjoy structuring an ambiguous
problem until they have tried it and seen how it went, so the evaluation is
what makes the resulting Preference informed rather than imagined. Second, it
names **Skills to Build** — a weak showing in an area the User nonetheless
wants more of becomes part of the Direction ("explore this, and here is what
to strengthen"), never a reason to point them elsewhere.

So: performance shapes reflection, and reflection shapes the recommendation.
Performance never reaches the recommendation directly.
