# Three-minute portfolio walkthrough

Record at a normal laptop width. Hide personal files, API keys and terminal windows.

## 0:00-0:20 - Product promise

Show the welcome screen.

Say: The Career Experiment helps people compare two plausible careers when descriptions and quizzes are not enough. It turns past experience into evidence and makes important unknowns visible before the user chooses what to test.

## 0:20-0:40 - Guided demo

Choose the five-minute guided demo.

Explain that fictional data lets a reviewer experience the mechanism without uploading a personal resume or spending API credit.

## 0:40-1:05 - Existing experience

Show the experience and activity review.

Explain that detailed resume sentences become stable canonical activities. Equivalent activities merge, while original wording and source experiences remain available.

Expand one original-resume wording control.

## 1:05-1:30 - Grouped preference review

Show one activity group.

Say: The prototype selects at most 10 informative activities, but it no longer asks about each one separately. Related activities are reviewed together. The user gives one preference for the group overall.

Point out the activity list, sources and the two career-specific explanations.

## 1:30-2:00 - Evidence map

Show both careers.

Say: Each percentage shows how many Core and Important activities in this career group appeared in the reviewed resume. It is not a skill or fit score.

Point out:

- the visible numerator and denominator;
- the group preference when matching evidence exists;
- "No preference evidence" when the career group has no matching past activity;
- important work still untested.

## 2:00-2:35 - Supported work trial

Choose a question and enter a direct-comparison trial.

Explain that both roles use the same company and scenario so the product compares the work rather than the industry. Show the primer, structured task, qualitative review and focused revision reminder.

Use the guided-demo sample evaluation to avoid a live API call.

## 2:35-3:00 - New evidence and limits

Show the synthesis.

Explain that response quality, response to feedback, preference and work reaction stay separate. The result can be inconclusive. One simulation is one new piece of evidence, not a career recommendation.

## Recording checklist

- Record at 1080p if possible.
- Keep cursor movement slow.
- Remove unrelated browser tabs.
- Never expose the environment file or API key.
- Add captions.
- Export an MP4 and an optional short GIF.
- Use a title card: "Past evidence -> unknown -> supported work trial."
